# ops_dashboard — 다컴스 운영 통합 대시보드 (로컬 전용)

채용 리드·타겟 기업 CRM·카드뉴스 성과·7개 서브에이전트 실행 현황을 한 페이지에서
보는 로컬 대시보드. 표준 라이브러리만 사용해 별도 설치 없이 바로 실행된다.

```bash
python3 ops_dashboard/server.py
# → http://127.0.0.1:8787 브라우저 자동으로 열림
```

## 무엇을 볼 수 있는가

| 탭 | 데이터 소스 | 편집 가능? |
|---|---|---|
| 채용 리드 | `data/dashboard.json` (`job_pipeline`가 생성) | 읽기 전용 |
| 타겟 기업 CRM | `data/target_companies.csv` | **편집 가능** |
| 카드뉴스 성과 | `data/card_news_metrics.csv` (`metrics_pipeline`이 생성) | 읽기 전용 |
| 자동화 실행 현황 | `outputs/<team>/latest.json` (7개 서브에이전트) | 읽기 전용 |

**타겟 기업 CRM만 편집 가능한 이유**: 나머지 세 탭은 각 파이프라인/에이전트가
실행할 때마다 통째로 덮어쓰는 산출물이라, 여기서 고쳐도 다음 실행에 사라진다.
타겟 기업 CRM은 사람이 직접 큐레이션·추적하는 유일한 데이터라 이 대시보드가
곧 편집 도구여야 한다.

## 편집하면 실제로 무슨 일이 일어나는가

셀을 고치거나(포커스 아웃/선택 변경 시 자동 저장), "+ 새 기업 추가"나 "삭제"를
누르면 **즉시 `data/target_companies.csv` 파일에 그대로 쓰인다**. 이 저장소를
쓰는 다른 도구(예: `cold-email-team` 서브에이전트, git)가 보는 파일과 완전히
같은 파일이다. 별도 DB나 클라우드 저장소가 없다 — 파일이 곧 데이터다.

## 왜 로컬 전용인가

인증이 전혀 없다. `127.0.0.1`(이 컴퓨터 자신)에만 열려 있고, 실행 중인
컴퓨터의 실제 파일을 누구나 요청만 보내면 바로 고칠 수 있는 구조라서 절대
공용 네트워크나 인터넷에 노출하면 안 된다(포트포워딩, `--bind 0.0.0.0`류
수정 금지).
